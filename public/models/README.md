# 3D Models Directory

Place your downloaded `.glb` 3D model files in this directory.

For the **Tata 407 Gold Cargo Truck (SFC)** integration:
1. Export the 3D model as a `.glb` (binary GLTF) file from your Meshy account.
2. Rename the exported file to `tata_407.glb`.
3. Save it directly inside this `public/models/` folder.

The web telemetry panel will automatically detect the file and render the interactive 3D model.
